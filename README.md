# Rafhaela Silva — Advocacia e Consultoria Jurídica

Site institucional em português para Rafhaela Silva, com sede em São Gotardo/MG e atendimento online no DF e exterior. Identidade em rosé, cobre, marfim e café derivada do logo; títulos em Cormorant Garamond e leitura em Manrope.

## Executar

Next.js 16.3.5, React 19.2.8 e Tailwind CSS 4.

    npm install
    npm run dev

Produção: npm run build e npm run start. Verificações: npm run lint e npx tsc --noEmit. Siga AGENTS.md e os guias locais de Next.js.

## Estrutura

- app/lib/brand.ts: dados da marca, nove relatos e links de contato.
- app/page.tsx: hero, apresentação, seis pilares com modais acessíveis, compromissos, etapas, avaliações, FAQ, contato e rodapé.
- app/globals.css: tema Tailwind 4 em @theme inline, cores, fontes, responsividade, foco e movimento reduzido.
- app/layout.tsx: fontes, metadados, favicon e tema do navegador.
- public/rafhaela-silva-logo.png: logo original, 1774×887, transparência preservada.
- public/rafhaela-silva-assessoria.png: publicação fotográfica original, 845×839.
- PRODUCT.md: fatos e limites de conteúdo.
- DESIGN.md e .impeccable/design.json: sistema visual vigente.
- .impeccable/rafhaela-silva-direction.md: justificativa das escolhas visuais.
- .impeccable/asset-origins.json: origem e integridade dos arquivos fornecidos.
